# MVVM Donation Receipt Generator

A bilingual English and Tamil donation receipt generator for MVVM.

## Features
- Live receipt preview
- Receipt number and date
- Donor details and donation purpose
- Amount in figures and auto-generated English words
- Cash, bank transfer and UPI payment modes
- Three authorization signatures: Treasurer, Chairman and Secretary
- Print or save as A4 PDF
- Browser-local receipt history

## Run locally
Open `index.html` in a modern browser. No build tools or backend are required.

## Free hosting with GitHub Pages
Open the repository Settings → Pages. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save. The site will be published at `https://altrinrejo022-commits.github.io/mvvm-receipt-generator/` after the Pages build completes.
